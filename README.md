# Центр Mac — сайт

Страница программы «Центр Mac»: удобство Mac для Windows 10 и 11 — поиск по Win+Пробел, панель музыки с текстом песен, снимки экрана, Finder и экран iPhone в одном файле.

Обычный статический сайт: HTML, CSS и немного JavaScript, без сборки и зависимостей.

| Файл | Что внутри |
|---|---|
| `index.html` | страница |
| `assets/style.css` | оформление, светлая и тёмная тема |
| `assets/app.js` | живой фон, анимации, вкладки скриншотов, сравнение Windows 10/11, обои по времени суток |
| `assets/version.js` | дата версии и размер файла — пишет `update-site.ps1` |
| `assets/img/` | скриншоты программ (демо-режим) и обои «Пейзаж дня» |
| `assets/demo/iphone.html` | страница отправки файлов с iPhone, показана в рамке телефона |
| `downloads/` | `mac-center.exe` (скачивается как «Центр Mac.exe») и `MacSuite.zip` с исходниками |
| `vercel.json` | заголовки для Vercel: файлы из `downloads` скачиваются, а не открываются |
| `assets/paper/` | слои бумажного пейзажа для параллакса на первом экране |
| `PROMPTS.md` | промты, чтобы сгенерировать эти слои в GPT |

## Посмотреть

Открыть `index.html` в браузере.

## Выложить на Vercel

1. vercel.com → **Add New… → Project** → выбрать репозиторий `mac-win`.
2. Framework Preset — **Other**, Build Command и Output Directory оставить пустыми.
3. **Deploy**. Каждый новый коммит в `main` обновит сайт сам.

## Новая версия программ

После сборки комплекта запустить `update-site.ps1` (он берёт свежие файлы из `D:\mac-wind\Комплект`), затем закоммитить и отправить изменения.
